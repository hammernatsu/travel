## 📔 實際遊記

這趟十天的旅程從東京的城市街景開始，接著飛往岡山、租車前往姬路，再跨過瀨戶內海進入四國。一路經過香川、德島、高知與愛媛，走過城堡、商店街、峽谷、古橋、海岸與溫泉，最後沿著瀨戶內海回到岡山搭機返台。

### Day 1｜9/25 從台灣飛往東京

早上從家裡出發，前往桃園國際機場，下午搭機飛抵成田，再乘電車進入東京。傍晚在六本木一帶落腳，稍作整理後搭地下鐵前往新宿。新宿車站周邊的燈光、人潮和密集街道，成了這趟旅程的開場，深夜再返回六本木住宿。

**實際足跡：** 台灣住家 → 桃園國際機場 → 成田機場 → 六本木 → 新宿 → 六本木

### Day 2｜9/26 合羽橋、上野、銀座與六本木

早上從六本木出發，搭地下鐵到淺草、合羽橋一帶，在松が谷的合羽橋道具街慢慢逛餐具、廚具與料理用品店。中午步行往上野、御徒町方向移動，午後再搭電車到銀座，在銀座四丁目附近活動了近兩小時。晚上回到六本木，在住宿附近吃飯、散步。

**實際足跡：** 六本木 → 合羽橋道具街 → 上野／御徒町 → 銀座 → 六本木

### Day 3｜9/27 飛往岡山，再到姬路

清晨從六本木前往羽田機場，搭國內線飛往岡山。抵達後取車，正式展開自駕行程。中午向東進入兵庫縣，途中短暫停靠休息站，午後抵達姬路，在姬路城周邊停留。傍晚入住姬路車站附近，晚上在市區用餐、散步。

**實際足跡：** 六本木 → 羽田機場 → 岡山機場 → 姬路城 → 姬路市區

### Day 4｜9/28 跨越瀨戶內海，抵達高松

早上先在姬路市區活動，之後開車向西，在龍野西休息站停靠，再往岡山方向前進並跨越瀨戶內海。下午來到香川縣丸龜一帶，途中採買、休息，傍晚抵達高松市中心，在古馬場町一帶住宿與用餐。

**實際足跡：** 姬路 → 龍野西休息站 → 岡山 → 瀨戶大橋 → 丸龜 → 高松

### Day 5｜9/29 鳴門海峽一日往返

早上從高松出發，沿高速公路往德島方向前進，在道之驛板野稍作休息後，繼續前往鳴門海岸。中午抵達鳴門觀光汽船附近，接著走訪鳴門海峽與大鳴門橋一帶。午後在大橋周邊停留、用餐，再驅車返回高松。

**實際足跡：** 高松 → 道之驛板野 → 鳴門觀光汽船 → 大鳴門橋／鳴門海峽 → 高松

### Day 6｜9/30 大步危、祖谷藤蔓橋，到高知

早上離開高松，向南穿越四國山地。途中經過綾川、財田，在道之驛たからだの里さいた停留後，沿國道進入德島縣深山。下午抵達大步危峽，之後轉入祖谷山區走訪祖谷藤蔓橋。傍晚離開祖谷繼續南下，進入高知並入住市區。

**實際足跡：** 高松 → 綾川 → 財田 → 大步危峽 → 祖谷藤蔓橋 → 高知市

### Day 7｜10/1 龍河洞、桂濱與高知市中心

早上由高知市前往香美市的龍河洞，在洞穴一帶停留超過兩小時。中午返回南國市方向，午後沿海前往桂濱，並在高知縣立坂本龍馬紀念館一帶停留。傍晚回到高知市中心，在帶屋町、弘人市場周邊活動。

**實際足跡：** 高知市 → 龍河洞 → 南國 → 桂濱／坂本龍馬紀念館 → 帶屋町／弘人市場 → 高知市

### Day 8｜10/2 沿仁淀川西行，前往松山

上午離開高知市，沿仁淀川方向向西，先到名越屋沉下橋，再在日高、佐川一帶停留。午後繼續沿國道 33 號深入仁淀川町，經久萬高原進入愛媛縣。傍晚抵達松山，晚上在大街道商店街一帶吃飯、散步。

**實際足跡：** 高知 → 名越屋沉下橋 → 日高／佐川 → 仁淀川町 → 久萬高原 → 松山大街道

### Day 9｜10/3 金刀比羅宮與道後溫泉

早上從松山出發向東橫越愛媛，途中經過西條與香川縣西部，中午抵達琴平。時間軸在金刀比羅宮一帶停留近兩小時。下午折返松山，傍晚抵達道後溫泉，在道後商店街與振鷺閣周邊停留了三個多小時，夜裡回到松山市中心住宿。

**實際足跡：** 松山 → 西條 → 金刀比羅宮 → 松山 → 道後溫泉 → 松山市區

### Day 10｜10/4 跨越瀨戶內海，從岡山返台

最後一天從松山出發，沿今治方向前進，再經瀨戶內海島嶼與本州方向北上。途中在今治、福山一帶短暫停靠，下午抵達岡山機場辦理還車與登機。傍晚搭機返台，晚上回到桃園與家中，十天的東京、瀨戶內與四國之旅正式結束。

**實際足跡：** 松山 → 今治 → 瀨戶內海跨海路線 → 福山 → 岡山機場 → 桃園 → 家
