# 🇲🇾 2025 任性馬來西亞七日遊記

::: tip 實際足跡
旅行日期為 2025/04/28–05/04。本文依 Google 時間軸、GPS 座標與飛行紀錄整理；這是一趟以吉隆坡為中心的獨旅。
:::

- **路線：** 桃園 → 吉隆坡 → 巴生谷各區 → 吉隆坡 → 桃園
- **航班：** 星宇航空 JX725、馬來西亞航空 MH366
- **主題：** 獨旅、吉隆坡城市散策、商場、美食與夜間街區

## 4/28｜抵達吉隆坡

上午由桃園搭乘星宇航空 JX725 前往吉隆坡。傍晚抵達市中心、入住武吉免登附近，晚上先在住宿周邊用餐與熟悉街區。

**實際足跡：** 桃園 → 吉隆坡國際機場 → 武吉免登

## 4/29｜雙峰塔、KLCC 與茨廠街

上午在住宿周邊活動，中午後前往 KLCC，在雙峰塔與公園周邊停留約三小時。傍晚返回飯店休息，晚上再前往茨廠街、舊市區方向散步與用餐，深夜回到武吉免登。

**實際足跡：** 武吉免登 → KLCC／雙峰塔 → 茨廠街／舊市區 → 武吉免登

## 4/30｜吉隆坡北側與 KL Sentral

上午在市中心活動，午後往吉隆坡北側短暫停留，再返回飯店。傍晚前往 KL Sentral、Brickfields 一帶，在車站商圈及附近街區活動至晚上。

**實際足跡：** 武吉免登 → 吉隆坡北側 → KL Sentral／Brickfields → 武吉免登

## 5/1｜八打靈再也與谷中城

中午離開市中心，前往八打靈再也方向，在商場及周邊停留數小時。傍晚轉往谷中城、南區商圈，晚間返回武吉免登。

**實際足跡：** 武吉免登 → 八打靈再也 → 谷中城／南區 → 武吉免登

## 5/2｜谷中城與吉隆坡北部

中午再次前往谷中城一帶，在購物中心及周邊活動至傍晚。晚餐時間轉往吉隆坡北部，之後返回住宿地，延續城市裡自由移動、隨興停留的獨旅節奏。

**實際足跡：** 武吉免登 → 谷中城 → 吉隆坡北部 → 武吉免登

## 5/3｜TRX、武吉免登與最後一夜

中午前往 TRX、武吉免登東側的新商圈，停留約四小時。傍晚返回住宿地，晚上在武吉免登密集走訪餐廳、商場與夜間街區，為旅程的最後一晚收尾。

**實際足跡：** 武吉免登 → TRX → 武吉免登商圈

## 5/4｜吉隆坡返台

清晨前往吉隆坡國際機場，辦理報到後搭乘馬來西亞航空 MH366 返回桃園。下午抵台並返家，結束七天馬來西亞獨旅。

**實際足跡：** 吉隆坡市中心 → 吉隆坡國際機場 → 桃園 → 家
