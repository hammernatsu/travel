# 🍂 2024 北海道到東北十六日遊記

::: tip 實際足跡
旅行日期為 2024/10/08–10/23。本文依 Google 時間軸、GPS 座標與飛行紀錄整理；可確認的景點保留名稱，短暫或定位不完整的停留則以城市與區域記錄。
:::

- **路線：** 桃園 → 新千歲 → 登別 → 函館 → 洞爺／二世谷 → 札幌／小樽 → 新千歲 → 仙台 → 東北北部 → 山形／藏王 → 東京 → 桃園
- **航班：** 酷航 TR892、ANA NH1224、長榮航空 BR195
- **主題：** 北海道自駕、函館與小樽、仙台與松島、東北縱走、藏王、東京散策

## 10/8｜飛抵北海道，前往登別

上午由桃園搭乘酷航 TR892 飛往新千歲。傍晚抵達北海道後取車，直接向南前往登別。晚上在登別溫泉街一帶用餐並住宿，開始這趟橫跨北海道與東北的長旅行。

**實際足跡：** 桃園 → 新千歲機場 → 登別溫泉

## 10/9｜登別散策，南下函館

早上走訪登別周邊，時間軸在登別海洋公園尼克斯、伊達時代村一帶留下長時間停留。午後離開登別，沿北海道南部公路一路前往函館，晚上抵達函館市區住宿。

**實際足跡：** 登別溫泉 → 登別景點區 → 北海道南部公路 → 函館

## 10/10｜函館一日散策

上午前往五稜郭一帶，中午轉往函館東南側，午後回到港區與舊市街。時間軸顯示在金森紅磚倉庫、元町周邊步行了兩個多小時，傍晚再於函館市區活動。

**實際足跡：** 函館市區 → 五稜郭 → 函館港／金森紅磚倉庫 → 元町

## 10/11｜離開函館，前往二世谷

上午在函館北側短暫停留，之後駕車向北，途中經過森、長萬部方向。下午進入羊蹄山、二世谷地區，傍晚入住二世谷附近，在山區度過一晚。

**實際足跡：** 函館 → 森／長萬部 → 二世谷

## 10/12｜二世谷、羊蹄山，再到札幌

早上在二世谷與羊蹄山周邊活動，沿途經過留壽都、京極方向，欣賞北海道秋季的山野景色。午後一路向札幌前進，傍晚抵達市中心，入住札幌車站、大通一帶。

**實際足跡：** 二世谷 → 留壽都／京極 → 札幌

## 10/13｜白色戀人公園、余市與小樽

上午先到札幌西側的白色戀人公園，之後沿海前往余市，在余市市區停留。下午抵達小樽，於小樽運河、堺町通周邊散步數小時，晚上再返回札幌。

**實際足跡：** 札幌 → 白色戀人公園 → 余市 → 小樽運河／堺町通 → 札幌

## 10/14｜札幌、定山溪與新千歲

早上在札幌市中心活動，中午前往定山溪，在溫泉區停留約兩個多小時。下午經札幌南側前往新千歲方向，傍晚在機場周邊活動並住宿，準備隔日搭乘日本國內線。

**實際足跡：** 札幌 → 定山溪 → 札幌南部 → 新千歲機場

## 10/15｜初次日本國內線：新千歲飛仙台

上午搭乘 ANA NH1224，由新千歲飛往仙台。抵達後前往松島，在松島灣、五大堂周邊停留，午後再到仙台港一帶。傍晚進入仙台市中心，晚上於車站周邊用餐、住宿。

**實際足跡：** 新千歲機場 → 仙台機場 → 松島 → 仙台港 → 仙台市區

## 10/16｜鹽竈、松島與仙台

早上由仙台前往鹽竈、松島方向，在港區與海岸停留數小時。午後回到仙台市區，接著前往仙台大觀音及城市西北側，晚上返回仙台住宿。

**實際足跡：** 仙台 → 鹽竈／松島 → 仙台大觀音 → 仙台市區

## 10/17｜一路北上，抵達八戶

早上離開仙台，沿東北地區公路向北。途中經宮城北部、一關方向，下午抵達盛岡短暫停留，之後繼續向北，晚上到達八戶住宿。這是全程移動距離較長的一天。

**實際足跡：** 仙台 → 宮城北部 → 一關周邊 → 盛岡 → 八戶

## 10/18｜八戶、十和田與奧入瀨方向

上午在八戶市區與港口周邊活動，之後向西進入青森縣內陸，經十和田方向前往山區。下午沿奧入瀨、八甲田周邊移動，傍晚再回到三澤、八戶東側住宿。

**實際足跡：** 八戶 → 十和田 → 奧入瀨／八甲田方向 → 三澤一帶

## 10/19｜八戶市場，南下山形

上午在八戶東側活動，並於市場、港區一帶停留約三個多小時。午後開始長途南下，經盛岡、花卷與宮城方向，晚上抵達山形市住宿。

**實際足跡：** 八戶 → 盛岡／花卷方向 → 宮城 → 山形市

## 10/20｜藏王溫泉與山形市

上午由山形市前往藏王山區，走訪藏王溫泉與纜車站周邊，在山區停留數小時。下午返回山形市中心，傍晚在車站附近用餐、逛街並住宿。

**實際足跡：** 山形市 → 藏王溫泉／藏王纜車 → 山形市

## 10/21｜告別東北，前往東京

早上在山形市區活動，之後經山形、宮城之間的山路回到仙台。中午抵達仙台車站一帶，午後搭乘鐵路南下東京，傍晚抵達上野、秋葉原周邊並住宿。

**實際足跡：** 山形 → 宮城 → 仙台 → 東京／上野

## 10/22｜東京車站與上野散策

上午前往東京車站、丸之內一帶，在車站周邊停留近三小時。午後回到上野，在上野公園、阿美橫町與附近街區活動，晚上返回住宿地。

**實際足跡：** 上野 → 東京車站／丸之內 → 上野公園／阿美橫町 → 上野

## 10/23｜東京最後散步，從成田返台

上午前往文京區、駒込一帶，之後經巢鴨方向移動。午後到新宿，在新宿車站周邊停留約兩小時，接著前往成田機場。晚上搭乘長榮航空 BR195 返回桃園，結束十六天的長旅行。

**實際足跡：** 上野 → 駒込／巢鴨 → 新宿 → 成田機場 → 桃園
