# ❄️ 2026 新潟雪國・東京八日遊記

::: tip 實際足跡
旅行日期為 2026/02/16–02/23。本文已由原本的行前計畫改為 Google 時間軸實際紀錄；定位重疊或無法精確辨識的短暫停留，以城市及區域名稱記錄，不將原計畫誤寫成實際造訪。

- **同行：** 前半段與媽媽同行，2/21 後為東京個人行程
- **路線：** 台北松山 → 東京／上野 → 新潟 → 月岡溫泉 → 村上／笹川流 → 彌彥／寺泊／燕三條 → 東京 → 台北松山
- **主題：** 雪國自駕、溫泉、日本海岸、美食與東京散策

## 2/16｜松山飛羽田，入住上野

下午由台北松山機場搭機前往羽田。晚上抵達日本後，經濱松町轉乘鐵路前往上野。辦理入住後，仍在上野、御徒町一帶短暫散步和用餐，接近午夜才回到飯店休息。

**實際足跡：** 台北松山機場 → 羽田機場 → 濱松町 → 上野／御徒町

## 2/17｜前往新潟，萬代島與月岡溫泉

早上由東京前往新潟，上午抵達新潟站。完成租車手續後，先在萬代島、Pier Bandai 一帶停留，享用海鮮並逛市場；下午再到沼垂地區短暫活動。

離開新潟市區後一路向東，途中短暫停靠，傍晚抵達月岡溫泉。當晚入住溫泉旅館，在雪國的第一晚好好泡湯與休息。

**實際足跡：** 上野／東京 → 新潟站 → Pier Bandai → 沼垂 → 月岡溫泉

## 2/18｜村上、日本海岸與山形縣方向

早上離開月岡溫泉後北上，先抵達村上市區，在老街與市區停留。接著繼續沿日本海岸前進，到笹川流一帶短暫停靠，沿途看海岸與冬季景色。

中午後路線轉向內陸，經新潟、山形縣界一帶前進，在置賜、南陽方向留下數個停留點，再由山區長途返回新潟市。晚上回到新潟站附近住宿。

這一天的實際路線與原先規劃的清津峽不同，是一趟由日本海岸深入山形縣、再折返新潟的長距離雪地自駕。

**實際足跡：** 月岡溫泉 → 村上 → 笹川流／日本海岸 → 山形縣置賜方向 → 新潟市

## 2/19｜彌彥、栃尾、寺泊與燕三條

早上由新潟市出發，首先前往彌彥神社。時間軸在神社周邊停留約一個多小時，之後繼續往內陸移動。

中午到栃尾一帶停留，接著折返日本海岸，午後抵達寺泊魚市場。市場與周邊停留將近一個半小時，適合品嘗海鮮、烤物與當地小吃。

離開寺泊後，沿燕、三條方向一路逛到傍晚；晚上返回新潟市區，在新潟站周邊用餐後回飯店。

**實際足跡：** 新潟市 → 彌彥神社 → 栃尾 → 寺泊魚市場 → 燕三條 → 新潟市

## 2/20｜燕三條工藝巡禮，搭新幹線回東京

早上再次往燕三條方向出發。上午至中午在燕市的工藝、產業設施與商店間移動，數個停留點集中在燕三條產業區，符合這一帶金屬加工與生活用品巡禮的特色。

下午回到新潟市，途中短暫停留與採買。回到新潟站附近後整理行李、還車，傍晚搭新幹線返回東京。晚上抵達東京站，再轉往羽田機場附近住宿。

**實際足跡：** 新潟市 → 燕三條工藝區 → 新潟市 → 新潟站 → 東京站 → 羽田機場

## 2/21｜送媽媽返台，回到東京散策

清晨由羽田機場周邊飯店出發，先陪媽媽辦理返台手續。上午離開機場，搭乘鐵路回到上野。

中午至下午在上野、御徒町一帶散步與用餐，之後前往新橋、銀座方向，傍晚至晚上在市中心停留數小時。夜間再回到上野住宿，旅程自此轉為個人東京行程。

**實際足跡：** 羽田機場 → 上野／御徒町 → 新橋／銀座 → 上野

## 2/22｜上野、合羽橋、秋葉原與日暮里

上午從上野出發，先在上野北側與公園周邊活動。中午往合羽橋、淺草西側移動，在餐具與廚具街區停留約一個小時。

午後一路步行到秋葉原，在電器街周邊短暫停留，再返回上野逛街。傍晚前往日暮里一帶用餐、散步，晚上回到上野，為返台前的最後一晚收尾。

**實際足跡：** 上野 → 合羽橋／淺草西側 → 秋葉原 → 上野 → 日暮里 → 上野

## 2/23｜羽田返台

早上由上野出發，搭乘鐵路前往羽田機場。完成報到後，中午搭機返回台北松山，下午抵台並返家，結束八天的新潟雪國與東京旅行。

**實際足跡：** 上野 → 羽田機場 → 台北松山機場 → 家
