# ❄️ 2024 名古屋・北陸・合掌村七日遊記

::: tip 實際足跡
旅行日期為 2024/12/18–12/24。本文依 Google 時間軸、GPS 座標與飛行紀錄整理。
:::

- **路線：** 桃園 → 名古屋 → 高山 → 奧飛驒／新穗高 → 富山 → 金澤 → 白川鄉 → 名古屋 → 桃園
- **航班：** 日本航空 JL8670／JL8671
- **主題：** 冬季自駕、飛驒高山、雪景、金澤散策、白川鄉合掌村

## 12/18｜抵達名古屋

下午由桃園搭機前往名古屋。晚上抵達名古屋市區後，在名古屋車站、榮一帶用餐與活動，並於市區住宿。

**實際足跡：** 桃園 → 名古屋 → 名古屋車站／榮

## 12/19｜名古屋出發，飛驒高山與奧飛驒

早上離開名古屋向北進入岐阜縣，中午抵達高山。時間軸在高山老街、宮川一帶停留數小時，午後再往奧飛驒方向移動，傍晚抵達山區住宿。

**實際足跡：** 名古屋 → 高山老街 → 奧飛驒溫泉鄉

## 12/20｜新穗高雪景，返回高山

上午前往新穗高一帶，在山區停留近四小時。冬季高山與雪景是這一天的主角。午後沿原路返回高山，晚上在高山市區用餐並住宿。

**實際足跡：** 奧飛驒 → 新穗高 → 高山市區

## 12/21｜經富山前往金澤

上午在高山市區最後散步，之後向北前往富山。下午於富山車站附近停留，再經小矢部方向進入石川縣。傍晚抵達金澤，在市中心用餐、逛街並住宿。

**實際足跡：** 高山 → 富山 → 小矢部 → 金澤

## 12/22｜金澤一日散策

上午從近江町市場周邊開始，在金澤市中心步行。接著前往兼六園、金澤城一帶，午後再走訪茶屋街與市區其他街區。晚上在金澤用餐，返回同一住宿地。

**實際足跡：** 近江町市場 → 兼六園／金澤城 → 茶屋街 → 金澤市區

## 12/23｜白川鄉合掌村，返回名古屋

早上離開金澤，經小矢部向南進入山區。中午抵達白川鄉合掌村，在村落停留超過兩小時。午後離開白川鄉，長途返回名古屋，晚上入住名古屋市區。

**實際足跡：** 金澤 → 小矢部 → 白川鄉合掌村 → 名古屋

## 12/24｜名古屋返台

上午在名古屋活動，之後前往機場，搭乘日本航空 JL8671 返回桃園，結束七天的冬季中部與北陸旅行。

**實際足跡：** 名古屋 → 中部國際機場 → 桃園
