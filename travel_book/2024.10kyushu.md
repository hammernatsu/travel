# 🍁 2024 福岡・九州五日遊記

::: tip 實際足跡
旅行日期為 2024/10/02–10/06。本文依 Google 時間軸、GPS 座標與飛行紀錄整理；短暫或無法可靠辨識的定位點以城市、區域或移動路線記錄。
:::

- **路線：** 桃園 → 福岡 → 熊本 → 阿蘇 → 別府／大分 → 九州北部 → 福岡 → 桃園
- **航班：** 星宇航空 JX840／JX841
- **交通：** 飛機、自駕、步行、福岡市區大眾運輸

## 10/2｜抵達福岡，南下熊本

上午搭乘星宇航空 JX840 從桃園飛往福岡。抵達福岡機場、完成入境後取車，下午先在鳥栖、基山方向停留，之後一路向南前往熊本。

晚上抵達熊本市區住宿。這一天以航班和長途移動為主，也替接下來幾天的九州自駕揭開序幕。

**實際足跡：** 桃園 → 福岡機場 → 鳥栖／基山一帶 → 熊本市

## 10/3｜熊本城、阿蘇，再到別府

早上走訪熊本城周邊，在城區停留約一小時。離開熊本後往東進入阿蘇地區，中午至午後在阿蘇山區停留，沿火山地形與高原公路繼續向大分縣前進。

傍晚抵達別府市區，入住後在車站及市中心一帶活動。從熊本的城下町到阿蘇火山，再到溫泉城市別府，是全程地貌變化最鮮明的一天。

**實際足跡：** 熊本市 → 熊本城 → 阿蘇山區 → 大分縣山區 → 別府

## 10/4｜別府地獄與大分市

早上先在別府市區活動，之後前往鐵輪溫泉、別府地獄一帶。時間軸在地獄溫泉區留下約一個半小時的停留，接著轉往大分市。

傍晚至晚上在大分車站、府內町周邊步行與用餐，並在大分市住宿。這一天沒有長距離趕路，主要在別府與大分兩座相鄰城市之間慢慢移動。

**實際足跡：** 別府市區 → 鐵輪／別府地獄 → 大分市區

## 10/5｜由大分返回福岡

早上離開大分，沿九州北部公路向西。途中在玖珠及筑後地區停留，午後繼續回到福岡市。

傍晚開始在福岡市中心步行，活動範圍集中於博多、住吉、天神之間；沿途用餐、逛街，晚上入住市中心。經過數日自駕後，旅行節奏重新回到都市散策。

**實際足跡：** 大分 → 玖珠一帶 → 筑後地區 → 博多／住吉／天神

## 10/6｜福岡市區與返台

上午由市中心搭地鐵前往福岡機場，在機場停留約兩個半小時辦理報到與候機。中午後搭乘星宇航空 JX841 返回桃園，下午抵台，再轉乘大眾運輸返家。

**實際足跡：** 福岡市區 → 福岡機場 → 桃園國際機場 → 家

| 10/3 | 別府 | 熊本城、阿蘇山區 |

這是一趟臨時成行、以自駕串起九州中北部的旅行。五天內從福岡一路南下熊本，跨過阿蘇抵達別府與大分，再繞回福岡；城郭、火山、溫泉與城市街景依序出現，形成緊湊但完整的一圈。
