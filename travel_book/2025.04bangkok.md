# 💦 2025 曼谷潑水節七日遊記

::: tip 實際足跡
旅行日期為 2025/04/10–04/16。本文依 Google 時間軸、GPS 座標與飛行紀錄整理；曼谷市中心定位密集，僅寫入可確認的區域與移動順序。
:::

- **路線：** 桃園 → 廊曼 → 曼谷市中心 → 素萬那普 → 桃園
- **航班：** 泰國獅航 SL395、泰國航空 TG636
- **主題：** 曼谷城市散策、潑水節、商場、美食與夜間活動

## 4/10｜前往桃園機場

白天由新竹、桃園方向前往機場。由於航班跨夜，當晚主要在桃園國際機場候機，準備飛往曼谷。

## 4/11｜抵達曼谷，城市初探

凌晨抵達廊曼機場，之後前往曼谷市中心入住。下午開始在舊城、昭披耶河東岸與市中心活動，晚上前往唐人街方向用餐，深夜返回住宿地。

**實際足跡：** 廊曼機場 → 曼谷市中心 → 舊城／河岸 → 唐人街

## 4/12｜市中心商圈與潑水節夜晚

午後由住宿地出發，先在暹羅、中央世界一帶活動，傍晚返回飯店休息。晚上再次外出，前往昭披耶河與市中心夜生活區域，活動延續至午夜。

**實際足跡：** 飯店 → 暹羅商圈 → 中央世界周邊 → 河岸／夜間活動區

## 4/13｜恰圖恰與宋干節

中午前往曼谷北側，在恰圖恰、公園與市集周邊停留數小時。傍晚回到市中心，晚上投入宋干節的街頭活動，在席隆、沙吞一帶移動至深夜。

**實際足跡：** 市中心 → 恰圖恰 → 市中心 → 席隆／沙吞

## 4/14｜暹羅與市中心潑水活動

中午過後前往暹羅、中央世界商圈，在購物中心和街區停留整個下午。傍晚繼續於市中心活動，夜間再到沙吞與河岸方向，感受潑水節期間的曼谷夜晚。

**實際足跡：** 沙吞 → 暹羅／中央世界 → 市中心夜間活動

## 4/15｜昭披耶河西岸與曼谷夜生活

午後前往昭披耶河西岸、吞武里方向，在河岸與寺廟區域活動。傍晚轉往東側的通羅、伊卡邁一帶，晚餐及夜間活動後返回住宿地。

**實際足跡：** 市中心 → 吞武里／昭披耶河西岸 → 通羅／伊卡邁 → 市中心

## 4/16｜最後採買，素萬那普返台

中午退房後，在暹羅與市中心完成最後採買。下午前往素萬那普機場，搭乘泰國航空 TG636 返回桃園，結束七天曼谷行。

**實際足跡：** 曼谷市中心 → 暹羅 → 素萬那普機場 → 桃園
